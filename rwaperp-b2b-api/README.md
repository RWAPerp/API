# RWAPerp B2B API

Integrate with RWA Perp through its REST and WebSocket APIs. Start with the quick start, then use the authentication, REST API, WebSocket, and API reference sections as needed.

> Default REST: `https://api-trade.rwaperp.xyz` · VIP REST: `https://api-vip.rwaperp.xyz` (same paths and `RWA-*` signing)\
> **X Layer only** (`chainId = 196`). No other chain is supported.\
> Complete account onboarding first. Then use the trading example with your API credentials. For signing details, see Authentication.

| Section            | Purpose                                                                                  |
| ------------------ | ---------------------------------------------------------------------------------------- |
| Quick start        | Install dependencies and run the trading example                                         |
| Authentication     | Open an account, bind an API key, and sign requests                                      |
| REST API           | Request and response conventions, trading, and withdrawals                               |
| WebSocket          | Public market streams and private account streams                                        |
| REST API reference | Parameters, request bodies, responses, authentication, and rate limits grouped by domain |
